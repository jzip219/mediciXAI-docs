Benchmark Version History
=========================

Purpose
-------

This page records the evolution of the benchmark specification and release posture.

It is not a changelog of code commits. It is a benchmark evolution record.

Version table
-------------

================= ========== ===============================================================
Version           Status     Summary
================= ========== ===============================================================
v0.x              Prototype  Exploratory consistency analysis and early contract shaping.
v1.0              Frozen     Reproducible benchmark specification, deterministic scoring,
                             semantic stability, and provenance.
v1.1              Planned    Additional benchmark releases and expanded cohorts.
================= ========== ===============================================================

How to read this page
---------------------

- ``v0.x`` describes the pre-frozen development phase.
- ``v1.0`` is the normative frozen specification documented in this Sphinx tree.
- ``v1.1`` is a forward-looking placeholder for future release planning.

Post-freeze v1.0 documentation posture
--------------------------------------

Benchmark Specification v1.0 remains frozen.

Documentation updates after the initial freeze are restricted to non-semantic usability improvements, such as navigation refinements and operator onboarding material.

These updates are not a specification version change and do not alter normative requirements, formulas, conformance criteria, or release artifact definitions.

Related historical implementation notes are maintained separately from this public documentation repository.
